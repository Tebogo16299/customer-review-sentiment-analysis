# Customer Review Sentiment Analysis Dashboard

## Project Overview

This project analyses customer reviews to understand customer sentiment, ratings, product categories, purchasing channels and customer locations.

The project combines Python for data analysis and Power BI for interactive data visualisation.

## Objectives

- Analyse customer review data
- Identify positive, negative and neutral sentiment
- Analyse customer ratings
- Compare purchasing channels
- Identify cities with the highest number of reviews
- Analyse sentiment across product categories
- Present insights using an interactive Power BI dashboard

## Tools and Technologies

- Python
- Power BI
- Pandas
- Data Visualisation
- Sentiment Analysis
- GitHub

## Project Process

1. Prepared and analysed the customer review dataset.
2. Used Python to perform data analysis and sentiment analysis.
3. Categorised customer reviews into Positive, Negative and Neutral sentiment.
4. Created visualisations to identify patterns and trends.
5. Built an interactive Power BI dashboard.
6. Uploaded the Python code, dashboard screenshot and project documentation to GitHub.

## Dashboard

The Power BI dashboard provides insights into:

- Customer sentiment distribution
- Reviews over time
- Reviews by purchase channel
- Reviews by customer city
- Average rating by product category
- Product category sentiment analysis

## Key Findings

- The majority of customer reviews are positive.
- Website purchases generated more reviews than mobile app purchases.
- Pretoria had the highest number of customer reviews among the cities analysed.
- Positive sentiment was the dominant sentiment across all product categories.
